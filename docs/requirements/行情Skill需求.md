## 1. 背景与定位

GXQuotes（Python 包名 `tzt-api`）目前是一个面向开发者的中焯行情 API 客户端库（4 个 Fetcher、13 个公开方法 + 共享传输层，详见[接口功能清单](../API/接口功能清单.md)）。

**项目目标**：在库能力之上封装一个**行情 Skill**——让智能体（agent）能以自然语言意图直接获取 A 股行情数据，无需了解底层 HTTP 接口、市场代码推断、字段单位换算等细节。

边界划分：

| 层 | 职责 | 载体 |
|----|------|------|
| **行情 Skill**（本项目标） | 意图 → 数据的封装：标的路由、参数校验、错误自诊断、结果口径统一 | Skill 定义（SKILL.md + 脚本入口） |
| tzt-api 库（现有，v1.1.0 → v2.0.0） | HTTP 客户端：进程级限流、重试、解析、单位换算、类型化异常 | `tzt_api` 包 |
| tztapi-agent（现有子智能体） | 中焯接口层的专家：新建/校验底层接口 | `~/.zcode/skills/tztapi-agent` |
| kline-qlib（兄弟仓库） | qlib 数据管道（批量下载 + bin 转换） | kline-fetcher 仓库 |

## 2. 使用场景（User Stories）

- 作为**量化研究员**，我想问「茅台近 3 年后复权日K」，直接得到带复权因子的标准 K 线数据，以便做回测
- 作为**策略开发者**，我想取「沪深300 指数 5 分钟K」，无需记忆指数代码与市场归属
- 作为**盘面分析师**，我想查「某股今天集合竞价与盘中分时」和「上周五的历史分时」，用于盘中行为分析
- 作为**题材跟踪者**，我想知道「这只股属于哪些概念板块」「某板块有哪些成份股、板块指数走势如何」

## 3. 功能需求（FR）

### FR1 K 线行情（日K / 分钟K）
- **周期**：日K；分钟K 1/5/15/30/60min
- **复权**：前复权（qfq）/ 后复权（hfq）/ 不复权（none）三种口径；个股场景提供**复权因子**（factor），成交量可还原为真实股数
- **取数方式**：按数量（最近 N 根）或按日期区间（begindate/enddate）
- **返回字段**：`date[/time] / open / high / low / close / volume / amount[/factor]`，单位统一为元、股
- 验收：三种复权口径单测覆盖；复权因子与公开基准（东财/新浪）抽样一致

### FR2 分时行情（实时 + 历史）
- **当日实时分时**：截至调用时点的盘中序列（3 秒粒度），含盘前集合竞价段（参考价、已配对量、未配对买卖量）与盘中段（最新价、均价、量、额）
- **历史分时**：指定交易日（YYYYMMDD）的同结构数据
- 口径说明：分时为原始成交序列，**无复权概念**（历史分时价格为当日实际价，除权日前后存在自然跳变）
- 验收：个股与指数均可取；两段数据（pre_market/trading）结构稳定

### FR3 标的解析契约（v2.0.0 重设计，核心变更）

**命名空间声明：个股与指数共用交易所前缀命名空间**（前缀语义 = 市场/交易所声明，与 qlib `SH000300`、kline-qlib 目录命名完全一致；qlib 查证：指数行情即 `SH000300` 形式，`CSI300` 只是成分股池名）：

```
sh600519  → 沪市 600519（个股）        sh000300 → 沪市 000300（沪深300 指数）
sz000001  → 深市 000001（平安银行）    sz399001 → 深市 399001（深证成指）
bj830799  → 北市 830799               bj899050 → 北市 899050（北证50）
```

**设计决策（2026-08-24 评审定稿）**：
1. **删除指数白名单**（`INDEX_CODE_MAP`/`is_index`/`get_index_info`/指数优先规则全删）——假设**上游调用方明确了解要指数还是个股数据**
2. 库层**零指数知识**：`infer_market` 仅按显式前缀 + 个股段位规则推断
3. **歧义即失败**：遇歧义裸码停止执行并抛异常，绝不静默猜测

**推断契约**（段位规则已于 2026-08-24 用 10032 全段实测标定）：

| 优先级 | 规则 | 结果 |
|---|---|---|
| 1 | 显式前缀 sh/sz/bj | 对应市场（个股/指数通用） |
| 2 | 调用方显式 `market` 参数 | 直接使用 |
| 3a | 裸码 600/601/603/605/688/689/**900(沪B)** | 沪（1） |
| 3b | 裸码 001/002/003/300/301 | 深（0） |
| 3c | 裸码 8/4/920（覆盖 830/430/870/920/899） | 北（103） |
| 4 | 裸码 **000xxx** | **抛 `AmbiguousCodeError`**（深市个股与沪市指数真实共存，静态不可分；实测 000001 双候选、000300 仅指数单候选，歧义性只有主数据知道） |
| 5 | 其余未知段位（含 200 深B[网关无数据]、93x 中证） | **抛 `UnknownCodeError`**（替换原"默认深"，fail-fast） |

**异常契约**：`MarketResolutionError(ValueError)` 基类 + `AmbiguousCodeError` + `UnknownCodeError`，顶层导出；消息含行动指引（如 *"000001 为歧义代码（深市个股/沪市指数共存）：个股请用 sz000001，指数请用 sh000001，或显式传 market"*）；在参数构造阶段抛出，**不发请求即失败**。

- 验收：段位规则表逐条单测；000xxx 与未知段位抛异常集成测试；26 指数测试改写为显式前缀形式全过

### FR4 概念板块归属与成份
- **个股 → 板块**：返回个股所属全部板块，类型标注（industry 行业 / region 地域 / concept 概念风格），支持按类型过滤
- **板块 → 成份股**：指定板块代码返回成份股清单（代码/名称/市场，含最新价/涨跌幅）；全量场景用生成器自动翻页（剔除板块自身）
- **板块发现**：获取全部概念板块列表（名称 ↔ 代码映射，实测约 390 个）
- 验收：600519 等样本股的板块归属与东方财富公开口径抽样一致

### FR5 板块/概念指数行情
- 板块指数日K（价格/量/额，单位已换算为元/点/%），支撑「板块走势如何」类问题
- 板块行情快照字段（最新价、涨跌幅）口径可用（v1.1.0 起已换算）

### FR6 Skill 交付形态（本项目的核心增量）

以 **Skill 定义**交付（SKILL.md + 基于本包的可执行脚本/代码片段），可被 Claude Code / ZCode 等 agent 运行时加载。

**标的意图路由 —— SecurityResolver（已选定方案：中焯搜索接口 10032，2026-08-24 实测验证）**：

```
输入：标的词（6位代码 / 中文名 / 拼音首字母）
  ↓ Action=10032（代码 → StockCodeList；名称/拼音 → StockCode）
解析：BinData | MarketNo | StockLabel 竖线多值字段
  → 候选列表 [{code, name, market, label}]，is_index = (label == "指数")
路由：
  唯一候选 → 调行情方法（显式 market）
  多候选   → 名称精确匹配优先；否则列候选向用户反问
  -200608 / -206008 → 报「未找到该标的」
```

- 实测路由样例：`"000300"`→唯一候选沪深300(m=1)，自动消除裸码歧义；`"000001"`→两候选→反问；`"贵州茅台"`→600519；`"zs"`→模糊多条
- **无静态别名表**（YAGNI）：CSI300/SSE50 等风格别名如需支持，走 10032 名称解析，不建映射表
- **错误自诊断**：失败时返回结构化、可行动的错误信息（标的不存在 / 无数据 / 网关不可达 / 参数非法）——库层 strict 模式类型化异常 + last_error 已具备，skill 层转译
- **安全铁律**（继承 tztapi-agent 约定）：只读 GET、限流 ≥0.1s（进程级共享，v1.1.0 已实现）、API 地址走环境变量不入库
- 验收：一个此前不了解本项目的 agent，仅凭 SKILL.md 完成 2. 节全部四类场景

## 4. 非功能需求（NFR）

| # | 需求 | 说明 |
|---|------|------|
| N1 | 数据口径 | 全接口价格/成交额=元、成交量=股、比率=%（v1.1.0 起含板块快照字段，已统一） |

| N3 | 失败语义 | 库层默认 None 兼容；strict 类型化异常 + last_error（✅ v1.1.0）；skill 层错误转译待 M2 |
| N4 | 依赖约束 | 零 numpy；仅 requests + PyYAML；Python ≥3.9（沿用库现状） |
| N5 | 可测试性 | 双层测试（mock 单测 + 真实网关集成测试），新能力同规则 |
| N6 | 兼容性（v2.0.0 改写） | **v2.0.0 为破坏性变更**：删除指数白名单与指数优先推断（`is_index`/`get_index_info`/`INDEX_CODE_MAP` 移除，裸 000xxx 与未知段位由"默认深"改为抛异常）。kline-qlib 需同步迁移：显式前缀取指数、市场判断改用新契约；`MARKET_TO_PREFIX`/`numeric_code` 保留 |
