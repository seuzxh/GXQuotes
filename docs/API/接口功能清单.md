# 数据接口功能清单

`tzt-api`（仓库 GXQuotes）已实现的数据接口总览，按模块组织。状态列基于 2026-08-24 集成实测（`pytest -m integration` 102 项全部通过，网关 `KLINE_API_BASE_URL` 真实环境；口径为 v1.1.0）。

## 总览

| 模块 | 类/入口 | 数据域 | 公开方法数 |
|------|-----|--------|-----------|
| `tzt_api/_transport.py` | `TZTClient` + 类型化异常 | 共享传输层（会话/进程级限流/重试） | — |
| `tzt_api/_base.py` | `KLineFetcher` | 日K / 交易日历 / 证券信息 + 共享底座 | 4 |
| `tzt_api/min_kline.py` | `MinKLineFetcher(KLineFetcher)` | 分钟K线 | 1 |
| `tzt_api/concept_plate.py` | `ConceptPlateFetcher(KLineFetcher)` | 概念板块 | 5 |
| `tzt_api/trend.py` | `TrendFetcher(KLineFetcher)` | 分时（集合竞价 + 盘中） | 3 |
| `tzt_api/market.py` | 纯函数（无类） | 市场推断规则单一事实源 | 4 |

四个 Fetcher 组合 `TZTClient`（v1.1.0）：HTTP 会话复用、**进程级共享限流**（默认 0.1s，多实例共同遵守）、失败重试（3 次、指数退避）、字段单位换算、指数优先市场推断。

## 一、日K线与共享底座 — `KLineFetcher`

### 1. `fetch_day_kline(code, count, market, begindate, enddate, adjust)` ✅
- **上游接口**：`Action=10002`，`klinetype=500`
- **取数方式**：`count`（根数，从最新向前）与 `begindate`/`enddate`（`YYYYMMDD` 日期区间）二选一，日期区间优先
- **复权**：`adjust` 可选 `qfq`（前复权）/ `hfq`（后复权）/ `none`（不复权）/ 数字，默认取配置 `kline.cqtype`（=2 后复权）
- **返回字段**：`date / open / high / low / close / volume / amount`
- 适用个股与指数（市场自动推断，指数优先）

### 2. `fetch_day_kline_with_factor(code, count, market, begindate, enddate)` ✅
- 在 `fetch_day_kline` 之上，分别请求后复权与不复权两套数据，合成**复权因子**：`factor = hfq_close / none_close`
- 成交量按因子复原为真实股数：`volume = none_volume / factor`
- 后复权数据异常（价格 ≤0、无对应不复权行、factor <1，属数据源 bug）时该行全部字段标 `NaN` 并告警
- 返回字段：日K 六字段 + `factor`。为 qlib 数据管道（kline-qlib 包）的核心供数方法

### 3. `fetch_trade_calendar(start_year=2000, end_year=2030)` ✅
- 以上证指数（000001，沪）逐年日K的日期字段推导 **A 股交易日历**，去重升序返回 `["YYYY-MM-DD", ...]`

### 4. `get_stock_info(code, market)` ✅
- `Action=10002` + `422.daycount=-1`，返回 `{code, name, market_sn}`（证券代码 / 名称 / 市场序号）

### 底座通用能力（继承给全部子类）
- **传输（v1.1.0 `TZTClient`）**：限流**进程级共享**（配置 `api.request_interval` 默认 0.1s，任意实例发起的请求共同间隔）；重试 `api.max_retries`（默认 3 次）指数退避
- **失败语义**：默认重试穷尽返回 `None`；`fetcher.last_error` 记录最近失败原因（`TZTConnectionError` 网络层 / `TZTAPIError` 网关业务错，携带 ErrorNo）；`KLineFetcher(strict=True)` 初始化可改为抛类型化异常（Skill 层推荐）
- 单位换算（2026-06 对照东财/新浪实测标定）：价格 `万分之一元 ÷ 1e6 → 元`、成交额 `万元 ÷ 1e4 → 元`、成交量原始即`股`（不换算）
- 市场推断静态方法：`is_index` / `get_index_info` / `infer_market`（委托 `tzt_api.market`）

## 二、分钟K线 — `MinKLineFetcher`

### 5. `fetch_min_kline(code, freq, count, market, pages, adjust)` ✅
- **上游接口**：`Action=10002`，freq→klinetype 映射：`1min→501`、`5min→502`、`15min→565`、`30min→566`、`60min→567`
- **翻页**：`pages > 1` 时以响应中 `{klinetype}.locator` 游标自动翻页，结果按时间排序去重
- **返回字段**：日K 六字段 + `time`（`HH:MM:SS`）；客户端可自行按时间切片
- 支持复权参数（同日K）

> KLINE_TYPE_MAP 中另定义了 `week→561`、`month→562` 映射，但**无专用公开方法**（`fetch_min_kline(freq="week")` 技术上可传，未作为承诺接口）。

## 三、概念板块 — `ConceptPlateFetcher`

概念板块市场代码固定 `market=44`。v1.1.0 起快照字段（price/change/change_pct/high/low）**已统一换算**（÷1e6 → 元/点、÷1000 → %，2026-08-24 实测标定自洽）。

### 6. `get_all_concept_plates(limit=None)` ✅
- **上游接口**：`Action=10007`（板块列表，按涨跌幅降序）
- **全量分页（v1.1.0）**：自动按 `start` 翻页（单页上限 100）直至短页，返回**全部**概念板块（实测约 390 个、4 页请求；v1.0.x 仅返回前 30）；`limit` 可截断
- 返回 `{code, name, market}` + 可选 `price / change / change_pct`（已换算）

### 7. `get_concept_plate_kline(plate_code, count=-220, market=44)` ✅
- **上游接口**：`Action=10002`（复用K线通道，`cqType=0` 不复权）
- 板块指数日K，返回字段与个股日K一致（已换算单位）

### 8. `get_concept_plate_stocks(plate_code, start=0, count=10)` ✅
- **上游接口**：`Action=10005`（板块成份股，`start/count` 分页）
- 返回 `{code, name, market}` + 可选 `price / change / change_pct / high / low`（已换算）
- ⚠️ 因固定 `block.include=1`，**返回首项为板块自身**（market=44），其后才是成份股

### 9. `iter_concept_plate_stocks(plate_code, page_size=100)` ✅（v1.1.0 新增）
- 生成器：自动翻页产出板块**全部成份股**（剔除 market=44 的板块自身行），全量约等于响应 `max` − 1

### 10. `get_stock_concept_plates(code, market, plate_type)` ✅
- **上游接口**：`Action=10000` 关联属性：`900`（行业板块）/ `901`（全部板块）/ `923`（地域板块），用 900/923 给 901 标注类型
- 返回 `{code, name, market, type}`，`type ∈ {industry, region, concept}`；`plate_type` 参数可按类型过滤
- ⚠️ 深市 `000xxx` 个股请用 `sz` 前缀或显式 `market`（指数优先规则会把它判为指数）

## 四、分时 — `TrendFetcher`

### 11. `fetch_intraday_trend(code, market)` ✅ 当日分时
### 12. `fetch_history_trend(code, date, market)` ✅ 历史分时（`date=YYYYMMDD`）
### 13. `fetch_trend(code, date=None)` ✅ 自动分发（`date` 为 None/"0" 走当日）

- **上游接口**：`Action=10001`，`trendtypes=-1`（当日 `date=0, daycount=0`；历史 `daycount=1`）
- **返回结构**：`{market_date, pre_market, trading}`，两段数据分别为：
  - `pre_market`（CallTrend，集合竞价，`phase="pre-market"`）：`ref_price`（参考价）/ `matched_vol`（已配对量）/ `non_matched_vol_buy` / `non_matched_vol_sell`（未配对买卖量）
  - `trading`（TrendOp，盘中，`phase="trading"`）：`last_price` / `avg_price`（均价）/ `volume` / `turnover`，时间粒度 3 秒
- 价格与成交额已按底座规则换算为元；适用个股与指数

## 五、市场规则 — `tzt_api.market`（纯函数，零依赖）

被本包与下游 kline-qlib 共享的**单一事实源**，判断顺序：显式前缀 > 指数优先 > 个股号段。

| 函数 | 作用 |
|------|------|
| `numeric_code(code)` | 剥离 sh/sz/bj 前缀（v1.1.0 起全部请求构造统一走此函数） |
| `is_index(code)` | 是否按指数处理（白名单或 399 前缀；显式 sz/bj 前缀强制按个股） |
| `get_index_info(code)` | 指数 `(名称, 市场代码)` 或 None |
| `infer_market(code)` | 推断市场代码：沪=1 / 深=0 / 北=103 |

- **指数白名单** `INDEX_CODE_MAP`：26 个常见指数（上证指数、沪深300、中证500/800/1000、科创50、创业板指、北证50 等）
- **号段规则**：沪 `600/601/603/605/688/689`；深 `000/001/002/003/300/301`；北 `8/4/920`；其余默认深
- ⚠️ **代码歧义**：裸码 `000001` 按指数优先判为上证指数（沪）；取深市平安银行需 `sz000001` 或显式 `market=0`

## 通用约定

- **失败语义**：默认请求最终失败或无数据统一返回 `None`（不抛异常）；`last_error` 可查原因，`strict=True` 初始化可启用类型化异常（v1.1.0）；`fetch_day_kline_with_factor` 的单行数据源异常标 `NaN`
- **单位**：全部行情接口的价格、成交额已换算为元，成交量为股，比率类（涨跌幅）为 %（v1.1.0 起含板块快照字段）
- **必填环境变量** `KLINE_API_BASE_URL`（未配置报 `EnvironmentError`）；`KLINE_CONFIG_PATH` 可选覆盖配置文件路径，其余参数见 `tzt_api/config/kline_config.yaml`
